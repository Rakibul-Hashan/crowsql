# Changelog

## v1.1.0
- New **Database → ERD** button: opens the database selected in OurSQL as an ER diagram in Crowfoot, with no manual import. Foreign keys become relationship lines.
- Crowfoot updated to v3.2 and OurSQL gets a small hidden message handler for this. No visible OurSQL feature changed.

## v1.0.0
- First merged release: Crowfoot v3.1 and OurSQL v1.3.3 in one site with a tab shell. Both apps are unchanged; each keeps its own data.
- OurSQL loads only when its tab is first opened.
- Hosting config for Vercel, Cloudflare Pages and Netlify, and a local test server.
